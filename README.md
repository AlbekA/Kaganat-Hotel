# Kaganat Hotel (Мейманкана Каганат) — Официальный сайт

Высококонверсионный сайт нового бутик-отеля 4★ в центре города Ош (ул. Алымбека Датка, 322а), созданный на базе данных карточки 2ГИС (рейтинг 4.9, 131 отзыв), 13-блочной продающей структуры и готовой интеграции с Telegram Bot.

## 🤖 Как подключить Telegram Bot

1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте **HTTP API Token**.
2. Узнайте свой `Chat ID` (через [@userinfobot](https://t.me/userinfobot) или добавив бота в нужную группу).
3. Добавьте параметры в файл `.env`:
   ```bash
   VITE_TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
   VITE_TELEGRAM_CHAT_ID="ВАШ_CHAT_ID"
   ```
   Либо укажите их напрямую в `src/services/telegramService.ts` в объекте `TELEGRAM_CONFIG`.
